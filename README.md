# 日札 · 把日子写成书

一本安静的数字日记本。纯前端、无依赖，打开 `index.html` 就能使用。

## 打开方式

- 直接双击 `index.html`；
- 或者在当前目录启动一个本地服务：

```powershell
python -m http.server 8137
```

然后访问 <http://127.0.0.1:8137>。

## 已经做好的功能

- **写日记**：标题、正文、日期、6 种心情、5 种天气、标签、收藏
- **书桌**：今日问候、写作统计、每日一问、最近日记、本月小日历
- **全部日记**：关键词搜索、按心情/年份/标签筛选
- **日历**：完整月历、有日记的日期标记、按天查看与补写
- **心情手记**：连续记录、字数统计、心情分布、常用标签、写作热力图、月度趋势
- **收藏**：集中查看被标星的日记
- **本地备份**：导出 JSON、导入 JSON、清空日记本
- **阅读体验**：浅色/夜间/跟随系统、手机与桌面自适应、键盘快捷键

## 数据说明

所有内容保存在浏览器 `localStorage` 的 `rizha.diary.v1` 中，不会上传到任何服务器。清除浏览器站点数据会同时删除日记，建议定期使用「偏好与备份 → 导出全部日记」保存副本。

首次打开会放入几页示例日记，顶部提示条可以关闭；「偏好与备份」里可以清空全部内容，从空白开始。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `N` | 写一篇新日记 |
| `Ctrl / ⌘ + K` | 搜索全部日记 |
| `/` | 打开搜索 |
| `Ctrl / ⌘ + S` | 在编辑器中保存 |
| `Esc` | 关闭当前浮层 |
